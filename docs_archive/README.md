# Historical Design Documents

This directory preserves earlier ATT design proposals and explains how their ideas developed into the current architecture.

Archived proposals may contain superseded mechanisms, unimplemented ideas, or inaccurate assumptions about earlier code.

They preserve design history and do not define current APIs, permissions, or runtime behavior.
