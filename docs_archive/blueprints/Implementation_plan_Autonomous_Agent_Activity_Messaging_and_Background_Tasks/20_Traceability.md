The replacement is complete only when every ordinary, governance, formation, failover, emergency, and supervisory model activity uses the same continuing-person coordination and no round-based execution survives.

Completeness also requires durable accepted messages and execution evidence, historical access boundaries, supported cancellation facts, consistent personal checkpoints, atomic restore behavior, and the confirmed recovery activation matrix.

The implementation must demonstrate those contracts without mandatory business work records, automatic private publication, hidden reasoning capture, implicit representatives, or model-driven copies of an existing person.

Planning statements describe target behavior rather than replace implementation and verification evidence.
